# 의자 쌓기

의자를 하나씩 쌓아 올리는 물리 게임. 하나라도 바닥에 떨어지면 끝.

- 플레이: https://41ways.github.io/chair-stack/ (같이 하기까지 전부, 서버 없음)
- 허브: https://41ways.github.io/norara/

## 하는 법

- 혼자 하기: 최고 기록 도전, 또는 한 화면에서 둘이 번갈아
- 같이 하기: 방을 만들어 최대 6명. 열린 방 목록에서 누르거나 방 코드·초대 링크로 들어온다. 비공개 방은 목록에 안 보인다. 채팅 있음. 방을 만든 사람이 나가면 방이 닫힌다
  - 차례는 무작위 순서로 돈다. 내 차례에 의자가 하나라도 떨어지면 그 사람이 진다
  - 45초 안에 못 놓거나 연결이 끊기면 차례가 넘어간다
- 기본판은 나무 의자만, 확장판은 룰렛이 고른다 (나무 의자 32%, 흔들의자 26%, 빈백 22%, 아기 식탁 의자 13%, 왕좌 7%)
- 테마는 오른쪽 위에서 바꾼다: 쇼룸, 하늘, 민트, 다크, 청소시간
- 의자는 처음에 아무 각도로나 나오고, 회전은 단위 없이 자유롭다(누르고 있는 동안 계속 돈다)
- 나무 의자는 다리 사이가 아래로 열려 있어 다른 의자 등받이나 다리에 걸쳐 끼울 수 있다
- 물리는 planck.js(Box2D). 실제 크기(1m = 80단위)와 실제 중력 9.8m/s²로 계산하고, 공기 저항·속도 제한·보정하는 힘은 없다. 무게중심이 받침 밖으로 나가면 엔진 계산대로 넘어간다. 멈춘 의자를 굳히는 잠재우기는 끈다. 무게중심은 화면에 표시하지 않는다

조작: 마우스(위치, 우클릭 누르는 동안 회전·Shift는 반대로, 클릭으로 놓기), 키보드(←→ 이동, Q/E 누르는 동안 회전, F 뒤집기, Space 놓기, 같이 할 때 Enter 채팅), 터치(끌어서 위치, 탭으로 놓기)

- 핑: G(한글 ㅎ)를 누른 채 마우스를 밀어 고르고 떼면 마우스 자리에 찍힌다. 왼쪽 ? 물음표, 위 ! 위험, 오른쪽 → 간다, 아래 취소. 연속 3번까지, 3번 찍으면 5초 쉰다. 같이 할 때는 방 사람 모두에게 보인다. 자리는 월드 좌표라 탑의 같은 곳에 찍힌다(`ping.js`, 3D와 같은 파일. 방 쪽 room.js도 3번·5초를 막는다)

## 구조

- `index.html` 화면 전부. 물리 엔진은 planck.js 1.4.3(jsDelivr)
- `room.js` 방 · 채팅 · 차례. v2.5부터 방을 만든 사람의 브라우저가 이걸 불러 돌린다. 다른 사람은 그 브라우저에 WebRTC(PeerJS 1.5.4)로 바로 붙고, 서로 찾는 것만 PeerJS 공용 중계(0.peerjs.com)를 거친다. 물리는 차례인 사람 화면이 계산해 위치를 흘려보내고, 멈추면 탑 전체 위치를 올린다. 방 쪽은 그걸 다음 차례의 출발점으로 저장하고, 어떤 의자가 나올지 정한다
- `worker.js`, `wrangler.toml` v2.4까지 쓰던 Cloudflare Worker + Durable Object 방 서버. 배포는 지웠고 기록으로만 남겨 둔다
- `lobby.js` 열린 방 목록. 서버 없이, 같이 하기 화면을 연 브라우저 중 먼저 온 하나가 PeerJS 이름 `chairstack2d-lobby` 를 잡아 목록을 맡는다. 방장은 방 정보를 거기에 올리고, 맡은 사람이 나가면 남은 사람 중 하나가 이어받는다. 비공개 방은 올리지 않는다. 3D와 같은 파일
- 회사·학교처럼 막힌 네트워크에서는 연결이 안 될 수 있다

## 실행과 배포

GitHub Pages(main 루트)라 푸시하면 반영된다. 로컬은 아무 정적 서버(`python3 -m http.server`)로 연다.
