# 의자 쌓기

전시대 위에 의자를 하나씩 쌓아 올리는 물리 게임. 하나라도 바닥에 떨어지면 끝.

https://41ways.github.io/chair-stack/

- 기본판: 나무 의자만 나온다
- 확장판: 매번 룰렛이 의자를 고른다 (나무 의자 32%, 흔들의자 26%, 빈백 22%, 아기 식탁 의자 13%, 왕좌 7%). 의자마다 놓기 어려운 이유가 다르다
- 테마: 쇼룸, 하늘, 민트, 다크, 청소시간
- 혼자 하면 최고 기록, 둘이서 하면 번갈아 올리고 내 차례에 떨어뜨린 사람이 진다

조작: 마우스(위치·휠 회전·클릭으로 놓기), 키보드(←→ 이동, Q/E 회전, F 뒤집기, Space 놓기), 터치(끌어서 위치, 탭으로 놓기)

정적 파일 하나(`index.html`)에 물리 엔진은 Matter.js(cdnjs)를 쓴다.
보드게임 Chairs(1999)의 규칙을 참고했다.
